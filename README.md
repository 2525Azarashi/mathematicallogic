# Tiny Tautology — 数理論理学 2026 の遊び場

「数理論理学（2026年度）」の理解を深めるための非公式学習サイト。
**サカイ（先輩・解説役）** と **リョウガ（受講生・質問役）** の対話で進み、各章に「さわれるラボ」があります。直感 → 形式化の順で学べる構成です。

- **GitHub**: https://github.com/2525Azarashi/mathematicallogic
- **Vercel**: https://mathematicallogic.vercel.app （`main` に push すると自動デプロイ。`vercel.json` で `npm run build` → `dist/` を静的配信）

## URL（ハッシュルーティング）
- `/#/` ホーム（ヒーローの式で ⊤/⊥ を切り替え、締切表示、講義一覧、全体マップ）
- `/#/lec/lec01` 〜 `/#/lec/lec04` 各回（`/#/lec/lec03/res` のように章 ID を付けると直接ジャンプ、`/ex` 演習、`/quiz` 類題）
- `/#/tools` 論理式ラボ（構文木・真理値表・CNF・Wang 証明図）
- `/#/sheet` チートシート ／ `/#/glossary` 用語集 ／ `/#/review` 復習リスト
- `/` キー or ⌘K でサイト内検索

## 技術構成
- Hono（Cloudflare Pages）がシェル HTML を返し、`public/static/` の ES モジュールで描画（ビルド不要の素の JS）
- `js/logic/core.js` — 論理エンジン：パーサ（講義の優先順位 ¬>∧>∨>⊃・左結合）、真理値表、恒真判定、CNF 段階変換、導出・反駁、LK の分解と Wang のアルゴリズム
- `js/widgets/` — 式入力（記号キーボード・エラー位置表示）、構文木 SVG、真理値表、CNF ステッパー、導出ボード、証明図ビルダー、クイズ
- `js/lib/chars.js` — キャラクター SVG（表情5種）とマスコット「トト」（⊤ の形、偽になると逆さまになって ⊥ になる）
- データ保存：localStorage のみ（既読章・クイズの正解状況）。サーバー側のストレージはなし

## デザイン
クリーム色のドット紙、インク色の太い輪郭線、ステッカー風のずらし影。フォントは Fredoka と Zen Maru Gothic。
色にはそれぞれ意味を持たせています：⊤ = ミント、⊥ = ピンク、¬ オレンジ・∧ 青・∨ 黄・⊃ 紫。各回にもテーマ色があります。

## モーション（キネティック・タイポグラフィ／UI アニメーション／インフォグラフィック）
- `js/lib/motion.js` + `css/motion.css`
  - **文字単位のキネティック・タイポ**：見出し・講義タイトル・章タイトルが1文字ずつ跳ねて入る。ヒーローでは ⊤ と ⊥ が回転して入れ替わり、「押して／ほどいて／ぶつけて／証明して」が切り替わる
  - **対話のタイピング演出**：吹き出しが順に出て、文字が打ち込まれるように現れる（話者のアバターに波紋）
  - スクロール連動で1語ずつ点灯する大見出し、2本の傾いたマーキー、パララックスで流れる背景の巨大文字・記号
  - 初回の導入画面（P → ¬P → P ∨ ¬P → ⊤）、ページ遷移時の3色ワイプ（行き先の名前を表示）
  - デスクトップ：追従するカスタムカーソル、磁石のように寄るボタン、3D チルトするカード、クリック時のリップル。下スクロールでナビを隠す
  - 数値のカウントアップ。`prefers-reduced-motion` のときはすべて止める
- `js/widgets/infographic.js`（スクロールで描画が始まる SVG/CSS 図解）
  - ホーム：数字カード4枚、14週タイムライン（進捗線・NOW マーカー）、成績配分のドーナツ（中間40%／期末60%）、恒真の確かめ方3つの比較
  - 第1回：集合と論理の記号の対応表 ／ 第2回：論理式の解剖図（構文木が描かれる）、2ⁿ の増え方グリッド
  - 第3回：CNF 変換の4段パイプライン、導出の「対消滅」ループアニメ ／ 第4回：構文論と意味論の比較、シーケントの読み方
  - 各回の冒頭：チャプター数・演習数・類題数と締切までの日数バー
- 性能：見えていない章は `content-visibility: auto` で描画を省略（長いページの初回描画を約 600ms から約 130ms に短縮）。章へのジャンプは高さ確定後に位置を補正する

## UI パターン（`lib/patterns.js` + `css/patterns.css`）
| パターン | 使っている場所 |
|---|---|
| **Pull to Refresh** | ホーム「今日の一問」カード：下に引っぱると別の問題（PC は ↻ ボタン） |
| **Skeleton Screen** | ページ遷移時（ワイプ後にシマー → 本文フェードイン）、復習リストの読み込み、`lazy()` |
| **Toast** | スタック型・種類別（ok / err / info / warn / qed）・「元に戻す」アクション・スワイプで消去 |
| **Bottom Sheet** | 本文中の用語（点線下線）・用語集カード・検索の用語結果 → 定義／登場回／関連語。ドラッグで閉じる・全画面化、Esc、フォーカストラップ |
| **Swipe Action** | 復習リスト：右スワイプ＝覚えた、左スワイプ＝削除（どちらも Undo トースト） |
| **Auto Complete** | サイト内検索（あいまい一致＋ハイライト）、論理式入力（有名な式・演習の式を候補に、恒真/充足可能チップ付き、Tab で確定）、用語集検索 |

- 復習リストは localStorage `tt:review`（`{id, kind, title, sub, href, at, done}`）。類題・演習・用語・今日の一問の「☆ あとで復習」から追加し、ナビの「復習」バッジに未完了数を表示します。
- 用語データは `data/glossary.js`（GLOSS / RELATED / ALIASES）。
